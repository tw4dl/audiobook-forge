# Code of Conduct

## Our standard

We want this project to be useful, safe, and welcoming. Contributors must:

- Be respectful and assume good intent.
- Give and accept useful, specific feedback.
- Focus on the work, not on people.
- Respect privacy and do not publish private material, book files, credentials, or model caches.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate disruption, doxxing, and publishing private information without permission.

## Enforcement

Report conduct problems privately to the repository maintainers through GitHub. Do not create a public issue for a sensitive report. Maintainers may edit, hide, or remove comments and may restrict participation when needed to protect the project community.

This policy applies in repository issues, pull requests, discussions, code review, and project spaces.
